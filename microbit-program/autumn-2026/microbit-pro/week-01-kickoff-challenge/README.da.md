## Materialer
- 1 micro:bit + USB-kabel pr. barn (V1 eller V2 — dagens spil kører på begge)
- Bærbar/Chromebook med makecode.microbit.org åben
- En makker til radiospillene (trin ⑤–⑥)

## Sessionsplan (60 min + 20 min pause + 30 min)

### Blok 1 — 60 min · Opvarmning + hovedspillet
- 5 min — velkommen tilbage, kig på 10-ugers Pro-kortet, vores ene regel: **del din kode hver uge**
- 15 min — **opvarmning:** byg og spil Sten-Saks-Papir-dyster
- 20 min — byg **Reaktionsdysten** sammen, og hold så en hurtig klasseturnering
- 20 min — begynd på **spil-stigen** (trin ①–②: terning, plat/krone)

### ☕ Pause — 20 min
Snacks og løbe rundt. Boards bliver på bordet.

### Blok 2 — 30 min · Byg flere spil
- 20 min — byg videre på spil i dit eget tempo (find en makker til radiospillene)
- 5 min — **fremvisning:** byt boards og spil hinandens spil
- 5 min — 🎉 **Kahoot-quiz** — hele holdet sammen

## 🔥 Opvarmning — Sten, Saks, Papir-dyst

Ryst din micro:bit for at kaste **sten, saks eller papir**, og dyst så med din sidemand — bedst af fem! En to-minutters byggeøvelse, der ryster rusten af.

    === "JavaScript"

        ```javascript
        input.onGesture(Gesture.Shake, function () {
            let choice = randint(0, 2)
            if (choice == 0) {
                basic.showIcon(IconNames.Square)
            } else if (choice == 1) {
                basic.showLeds(`
                    # # # # #
                    # # # # #
                    # # # # #
                    # # # # #
                    # # # # #
                    `)
            } else {
                basic.showIcon(IconNames.Scissors)
            }
        })
        ```

    === "Python"

        ```python
        def on_gesture_shake():
            choice = randint(0, 2)
            if choice == 0:
                basic.show_icon(IconNames.SQUARE)
            elif choice == 1:
                basic.show_leds("""

                basic.show_icon(IconNames.SCISSORS)
        ```

        ```javascript
        let armed = false
        input.onGesture(Gesture.Shake, function () {
            armed = false
            basic.showIcon(IconNames.Asleep)
            basic.pause(randint(1000, 5000))
            basic.showIcon(IconNames.Target)
            armed = true
        })
        input.onButtonPressed(Button.A, function () {
            if (armed) {

                basic.showString("A")

                armed = false
                basic.showString("B")
            }
        })
        ```

        ```python
        armed = False
        def on_gesture_shake():
            global armed
            armed = False
            basic.show_icon(IconNames.ASLEEP)
            basic.pause(randint(1000, 5000))
            basic.show_icon(IconNames.TARGET)
            armed = True
        input.on_gesture(Gesture.SHAKE, on_gesture_shake)

        def on_button_pressed_a():
            global armed
            if armed:
                armed = False
                basic.show_string("A")
        input.on_button_pressed(Button.A, on_button_pressed_a)

        def on_button_pressed_b():
            global armed
            if armed:
                armed = False
                basic.show_string("B")
        input.on_button_pressed(Button.B, on_button_pressed_b)
        ```

!!! note "Til hjælpere — sådan virker stigen"
    Alle bygger **Reaktionsdysten** først (den fælles sejr) og vælger derefter spil i deres eget tempo. Radiospillene (⑤–⑥) kræver en makker. Alle spil her bruger enkle, velkendte blokke — ryst, knapper, tilfældig, vis — så det handler om *leg og selvtillid* på dag ét; det sensortunge kommer senere på semesteret.
