# Uge 3 Kahoot — huskeseddel (dansk)

Spørgsmål OG svar er på dansk. Blok-navne er de rigtige danske MakeCode-navne
(sæt editoren til Dansk: ⚙️ → Sprog → Dansk): *start melodi*, *radio send nummer*,
*når radio modtager*, *vælg tilfældig*, *hvis / ellers*, *for altid*, *digital læs pin*, *sæt pull pin … op*.

Uge 3 dækker **begge hold**: begyndernes Spil-lab 2 (musik, radio, spåkugle,
kærlighedsmåler) og Pro'ernes pinball-kontakter (digitalt input, `for altid`-løkker,
kant-detektion, tilstand). Blandede hold med én Beginner + én Pro fungerer godt.

Kahoot-import kan **ikke** indeholde billeder — importér `week-03-da.xlsx` for teksten,
og tilføj så et billede pr. spørgsmål i Kahoot-editoren (indbygget billedsøgning).
Rigtigt svar står i **forskellige positioner** (A–D), og **ingen spørgsmål gentager uge 1–2**.
