# Week 1 — Kickoff & recap

**Goal:** get everyone excited about the 10-week build, agree on a theme, and warm up MakeCode.

**Reference tutorial:** https://makecode.microbit.org/projects/combination-lock (variables + if/else refresh)

## What you'll do
Look at real pinball builds, sketch your machine on paper as a group, and write a tiny "welcome" program so everyone remembers the download-to-board flow.

## Example code — a welcome screen
```blocks
on start:
    show string "PINBALL"
    show icon (heart)
```

## Session outline (60 min)
- 15 min — show the reference builds/videos (ctrl design pinball, PinBox 3000 + micro:bit) so kids see the end goal
- 30 min — Combination Lock tutorial as a warm-up/refresher, then type the welcome program above and flash it
- 15 min — plan the machine as a group: theme, rough layout sketch on paper

## ✅ Done when
- Every board, when flashed, shows the welcome message and a heart.
- The group has agreed on a **theme** and sketched a rough paper layout.
- Everyone remembers the download-to-board flow from Group A.
