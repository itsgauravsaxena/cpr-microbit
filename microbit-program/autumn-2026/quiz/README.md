# 🎉 End-of-session quiz

_[← Autumn 2026](../README.md)_

A short, fun quiz to finish every session — **both groups play together**. Each week has six questions: four about what we've been building, and two just for fun 🎉.

!!! tip "How to run it"
    1. Create a free quiz at <https://kahoot.com> (or use any quiz app / just read the questions aloud).
    2. Copy that week's questions and options in — the **✅ answer is the first option** in each list below, so shuffle them in the app.
    3. Project it, hand out devices (or play in teams), and run it in the last 5 minutes.
    4. Mixed group? Teams of 2 with one Beginner + one Pro works nicely.
