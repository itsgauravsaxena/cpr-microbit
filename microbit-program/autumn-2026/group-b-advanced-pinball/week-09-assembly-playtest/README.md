# Week 9 — Assembly + first playtest

**Goal:** bring the cabinet, printed parts, micro:bit, sensors, and wiring together — then play it for the first time.

## What you'll do
- Lay out all parts and review the assembly order
- Fit the printed bumpers and sensor mounts, wire the sensors to the micro:bit pins (P1, P2…)
- Power on and run a **first playtest** — does the score go up? does GAME OVER work?
- Write down every bug you find (you'll fix them in week 10)

## Session outline (60 min)
- 10 min — lay out parts, test each printed piece fits
- 35 min — assemble and wire; power on
- 15 min — first playtest; list the bugs and rough spots

## Notes
Assembly always runs long with kids — it's fine if some finishing spills into week 10. Track common bugs here.
