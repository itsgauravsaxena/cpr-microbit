# Week 8 — Assembly

**Goal:** bring together the cabinet/structure, kid-designed printed parts, sensors, and wiring.

## Session outline (60 min)
- 10 min — lay out all parts, review assembly order
- 40 min — assemble, test each part individually before final assembly
- 10 min — first full power-on test

## Notes
This week tends to run long — consider extra time or splitting across two sessions if needed.
