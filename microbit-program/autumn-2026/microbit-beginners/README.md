# micro:bit Beginners

Ages 8-10, brand new to coding. 1-hour sessions, physical micro:bits for everyone.

Week 1 is a single project so kids get comfortable with the editor without feeling rushed. From week 2 on, official MakeCode tutorials run ~15-25 minutes each, so two are combined per session to fill the hour. After the basics are down, two mini-projects stretch across two weeks each — a motor-driven robot (Ticklebot, weeks 5-6) and a radio transmitter/receiver build (weeks 7-8) — with each week written up separately so every session has its own instructions.

## Materials checklist
- Micro:bits (1-2 per kid for radio weeks) + USB cables or battery packs
- Laptops/Chromebooks with browser access to makecode.microbit.org
- A screen/projector to run tutorials in front of the group
- Weeks 5-6: 2 small servos + a touch-sensing material (crocodile clip / conductive tape) per Ticklebot
