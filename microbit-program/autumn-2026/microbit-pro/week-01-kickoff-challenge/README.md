## Materials
- 1 micro:bit + USB cable per kid (V1 or V2 — today's games run on both)
- Laptop/Chromebook with makecode.microbit.org open
- A partner for the radio games (rungs ⑤–⑥)

## Session plan (60 min + 20 min break + 30 min)

### Block 1 — 60 min · Warm up + the main game
- 5 min — welcome back, a look at the 10-week Pro map, our one rule: **share your code every week**
- 15 min — **warm-up:** build & play Rock-Paper-Scissors duels
- 20 min — build the **Reaction Duel** together, then run a quick class tournament
- 20 min — start the **games ladder** (rungs ①–②: dice, coin flip)

### ☕ Break — 20 min
Snacks and running around. Boards stay on the table.

### Block 2 — 30 min · Build more games
- 20 min — keep building games at your own pace (grab a partner for the radio ones)
- 5 min — **showcase:** swap boards and play each other's games
- 5 min — 🎉 **Kahoot quiz** — whole group together

## 🔥 Warm-up — Rock, Paper, Scissors duel

Shake your micro:bit to throw **rock, paper or scissors**, then duel the person next to you — best of five! A two-minute build to knock the rust off.

        ```javascript
        input.onGesture(Gesture.Shake, function () {
            let choice = randint(0, 2)
            if (choice == 0) {
                basic.showIcon(IconNames.Square)
            } else if (choice == 1) {
                basic.showLeds(`
                    # # # # #
                    # # # # #

                basic.showIcon(IconNames.Scissors)
            }
        })
        ```

    === "Python"

        ```python
        def on_gesture_shake():
            choice = randint(0, 2)

                basic.show_leds("""
                    # # # # #

                    """)
            else:
                basic.show_icon(IconNames.SCISSORS)
        ```

??? example "👀 Run it, or read the code"

    === "Blocks & simulator"

        ```makecode
        auto
        ```

    === "JavaScript"

        ```javascript
        let armed = false
        input.onGesture(Gesture.Shake, function () {
            armed = false
            basic.showIcon(IconNames.Asleep)
            basic.pause(randint(1000, 5000))
            basic.showIcon(IconNames.Target)
            armed = true
        })
        input.onButtonPressed(Button.A, function () {
            if (armed) {
                armed = false
                basic.showString("A")
            }
        })
        input.onButtonPressed(Button.B, function () {
            if (armed) {
                armed = false
                basic.showString("B")
            }
        })
        ```

    === "Python"

        ```python
        armed = False
        def on_gesture_shake():
            global armed
            armed = False
            basic.show_icon(IconNames.ASLEEP)
            basic.pause(randint(1000, 5000))
            basic.show_icon(IconNames.TARGET)
            armed = True
        input.on_gesture(Gesture.SHAKE, on_gesture_shake)

        def on_button_pressed_a():
            global armed
            if armed:
                armed = False
                basic.show_string("A")
        input.on_button_pressed(Button.A, on_button_pressed_a)

        def on_button_pressed_b():
            global armed
            if armed:
                armed = False
                basic.show_string("B")
        input.on_button_pressed(Button.B, on_button_pressed_b)
        ```
