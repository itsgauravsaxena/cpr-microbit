# Autumn 2026 — 10-Week Program

_[← All terms](../README.md)_

Two micro:bit groups, split by experience. 1-hour sessions, physical micro:bits for everyone, all built on official micro:bit Foundation / MakeCode material.

## Groups

- **[micro:bit Beginners](./microbit-beginners/README.md)** — brand new to coding. Ten weeks of official MakeCode projects: flashing heart, smiley buttons, dice, reaction games, a servo Ticklebot, radio messaging and a beacon hunt, finishing with a showcase.
- **[micro:bit Pro](./microbit-pro/README.md)** — already comfortable with MakeCode and ready for a challenge. Ten advanced projects: sensors and data, motion-controlled games, sound, multiplayer radio games, a digital pet, a motion instrument, and a two-week build-your-own capstone.

Both groups are **micro:bit only** — no 3D design this term.

## Repo structure

Each week has its own folder with:
- `README.md` — goal, what you'll build, example code, session outline and a ✅ Done-when checklist
- `code/` — where to drop the exported MakeCode project for that week (`.hex` file, or the shareable `makecode.microbit.org/_xxxxx` link pasted into a text file)

## Teaching approach

MakeCode's built-in **Tutorials** mode walks through projects step-by-step with pictures and a live simulator — project it on a screen and let the tutorial do the explaining. Pro sessions lean more on live coding and challenges than on step-by-step tutorials.
