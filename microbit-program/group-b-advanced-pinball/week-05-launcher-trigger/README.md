# Week 5 — Program the launcher/flipper trigger

**Goal:** button press or accelerometer tap = "flip"/"launch" event, with sound + LED feedback.

## Session outline (60 min)
- 10 min recap
- 40 min — program the trigger event; if servos are available, this is the week to wire one up to actually move a flipper (search "servo" under makecode.microbit.org/projects for reference blocks)
- 10 min — test

## Notes
If no servo, flippers can be simple manual/spring mechanisms — the micro:bit just gives sound/light feedback on the trigger.
