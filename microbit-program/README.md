## How this repo is organized

- Each **term** has its own folder (e.g. `autumn-2026/`).
- Inside a term, each **group** has a folder, and each **week** has a folder with its `README.md` (goal, tutorial links, session outline) and a `code/` folder for the exported MakeCode project (`.hex` file or a `link.md` with the shareable link).
- English is the source of truth; Danish translations live beside each page as `README.da.md`.
